# COACH02: manual exercise extension for COACH01

25/10/2026. Outcome: operator opens Manual Training from COACH01, explicitly synchronizes independent browser/server clocks, obtains a mock-only lease after neutral, practices hover/straight flight/yaw recovery, records axes+key events+authority+clock evidence, exports/reimports a replay package, and sees source-bound grading. Same assistant switches Contractor/Builder/Verify, no independent human QA.

This increment uses a versioned first-order velocity reference model, not 6DOF/Hera/ArduPilot/HID qualification. No real flight/SITL, APK, SDK, external AI/model inference or signature. Scripted reference controllers are labeled SCRIPTED_MOCK, never pilot/AI evidence. AUTO Beta05 reports stay separate and cannot become manual training evidence.

Architecture: pure deterministic engine + targets/model; Node durable hash-chained append-before-publication journal; replay/receiver independently recomputes every action/state and grade; manual UI and /api/training routes registered in current COACH01 host. Source changes limited to existing pilot/coach01/server.mjs and index.html for integration; archive exact prior bytes. All other COACH01 modules, reports, source/candidate/canonical SOT/ENDURE remain unchanged.

AC1 Three fixed exercises: hover, smooth straight transit/hold, yaw/recover. State ENU meters, heading degrees; controls normalized roll/pitch/throttle/yaw are body-velocity/yaw-rate references, not motor/PWM commands. Profile/tolerances/version/provenance pinned in each journal.
AC2 Every step records source clock identity/time, original key callback receipt timestamp (not physical HID time), normalized axes, source kind, session/boot/operator, lease/generation and receiver timestamp. Four-timestamp offset interval; bound uncertainty/age/clock drift. No host/guest clock merge or silent rescale.
AC3 Explicit sync→neutral→grant; rejected input never moves model. Revoke/expiry/background/clock regression or restart cannot auto restore authority. Target/boot/operator/seq/repeated stale lease rejected. Input sampling and human key changes distinguished.
AC4 Durable observation publication: clone candidate engine, append+fsync hash-chain row, then commit in-memory state/respond. Failure leaves no acknowledged state. Bound rows/bytes/quota; no auto deletion. Pending runs export as INCOMPLETE; restart never reactivates old engine/lease. Export/import retains source bytes and checks state/grade recomputation, not ACK/summary alone.
AC5 Grading: exercise coverage, target error, heading/altitude, normalized stick variation, correlation source/sim clocks and provenance; missing authority/time/frames blocks qualification regardless of accuracy. No total skill percentage or Hera transfer claim. Recommendations cite raw rows.
AC6 UI keyboard W/S,A/D,R/F,Q/E and mock axes panel with neutral-first grant, explicit start/stop/revoke, replay/timeline, report and package export/import. Visibility/focus clears intent, stops ticking and revokes when reachable. No queued automatic POST retry. Native controls/browser rendering NOT_CHECKED while browser blocked.
AC7 Analytic/adversarial corpus, scripted closed-loop reference and bad-input examples; recompute in cold process, HTTP disk/restart tests, independent math checks; user outcome vs AI/human baseline NOT_MEASURED. Preserve old missing-path incidents honestly.

Budgets: gate20GiB admission/10GiB+256MiB reserve; training store64MiB, one active session, <=20s simulated exercise at50ms/400steps, max2000rows/8MiB per run, 30minute host lifetime unchanged. Source clock handshake RTT<=200ms/width<=50ms, age<=30s/drift100ppm, command age upper<=200ms/lease200ms. These are engineering mock thresholds, not flight safety certification. No automatic mutation retries or cleanup. Own verification evidence <=64MiB.

Implementation clarification: neutral → grant → sampling begins through a single explicit “Nhận quyền và bắt đầu” button; the 200ms lease is not extended to hide UI latency. Keyboard source also records heldCodes snapshots and checks axes/event correlation. Prior keyboard packages without snapshots remain replayable but are not physical/source authenticated. A callback snapshot is acquired again before grant; opposing held keys cannot stand in for physically released neutral input.
