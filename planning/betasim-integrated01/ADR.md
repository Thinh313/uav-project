## Whole-pipeline capacity, 2026-10-30

Independent causal mock measured the earlier native path at three DATA RPCs and7702serializedbytes/input. At20Hz/600s this exceeded both32768RPC and the8MiB lifecycle owner budget. That design is rejected before actual admission. The replacement stages authenticated input, original clock/grant proof and RC intent into one genuine durable Root transaction before physical send. Original signed UTF8 input remains losslessly in native AJ02; Root semantic AJZ blocks reconstruct their exact original records with bounded dictionaries and hashes. No staged object may claim durability. Every original numeric quota, input250ms/lease200ms and fsync-before-send check remains.

Video frame proofs batch at most two encoded frames per commit, waiting at most40ms. Original three-credit accounting continues to include queued records while the batch waits. Both original proofs commit before either corresponding packet publishes; late/error/STOP cannot replay. Lossless media proof encoding preserves the15MiB DTO owner. Forecast includes single-frame batches and every other writer, not a best-case half-rate estimate.

The20000main HTTP-request cap also rejected polling architecture: native input alone requires12000requests/600s, while20Hz scene polling would add12000. Read-only bounded SSE streams replace recurring scene/state HTTP requests; connections count once, observations are not new HTTP requests. Source/backend physics frames remain fully journaled. Scene events carry the original Node send clock and use the existing publisher's independently calibrated browser-to-Node interval, so queued SSE data cannot acquire fresh receive timestamps. EOF/backpressure closes the observation stream without automatic reconnection or control restoration. Root's passive state observer runs at2Hz; native input and operator heartbeat timing do not change.

Thirty-second video windows retain original sample and quality gates. Versioned lossless groups hold at most three original windows/report, eight physical reports,4096samples/window and32768samples total (the original8×4096ceiling). Physical report limit512KiB, bounded group inflation3×512KiB and all byte owners remain. Extended observation ends only at a complete window boundary after original mission completion (minimum three windows), maximum24windows; partial/fault collections cannot certify coverage.

Video observation and payload command authority are separate. Expiry of the original60000ms command lease does not silently mint a new lease and does not require erasing an already selected, boot-bound read-only camera stream.
