# BETA-SIM integrated runtime handoff

This directory contains the new isolated source provider. It is not a signed production application and no Android/SITL campaign has been launched from these helpers. Frozen inputs and ENDURE were read only.

Root entry is `root-owner.py`. Its finite autonomous process creates one fresh campaign slot `r01` through `r08`, owns the guardian/AP/backend/Node/Android observation DAG, and records terminal closure without waiting for another model turn. Use `--inspect` only after the new candidate is frozen. Actual arguments are candidate path/SHA, exact Node and image/spec, source-held scenario, run, campaign slot, and `--seconds 180` or `760`. The latter requires digest-bound independently accepted short evidence for the same release/config. No source candidate is currently emitted; source/writer contract gates intentionally fail until final source pins and native development build are held.

The public Android UI scenario is the only normal product intent source. Private commands permit native enrollment, one planned native generation rollover, read-only status, sealing and raw export. They cannot ARM, set a mode, grant input or select a payload. Node owns one Workbench MAVLink writer, connected only to Root's existing AP proxy. Root commits original byte streams before forwarding. All input has original Android signed receipt and source-authority/clock fences, 250 ms freshness and 200 ms lease. Native AJ02 stores the exact signed input. A combined MANUAL_INPUT_TRANSACTION is committed once through Root before physical RC transmission. AJZ01 reconstructs every semantic row, exact UTF8/hash and clock; compression does not drop frames.

`ProductWriter` enforces unchanged shared byte/owner caps before physical writes. Its fixed DATA and optional read-only SCENE roles share one Unix namespace and have finite sequences, queues, frames and deadlines. File write sequences are not misclassified as Android STATUS requests. Root actor inventory, frozen leaf pins, source graph, native physical/logical journal scope, AVD growth and disk/power guards remain separately required.

The source scene is a read-only post-STAGE projection, and media image proof validates an exact original Root frame in a bounded 64-frame registry. Scene serialization and browser backpressure cannot block physics or control. Visual cache drops never drop physical frames. Audio/graphics sources are simulator evidence, not physical camera images.

`FlightIntervalTracker` incrementally validates original committed CRC transport, retains the first AUTO command ingress and the first complete genuine landed/disarmed group after observed AUTO. Explicit AUTO resume after an observed non-AUTO mode keeps that first bound; a pending AUTO cannot be retried. A separate cold thread joins every AUTO wire to exact closed flight AJZ and workspace review before the private proof is available. Node converts Root bounds using original two-clock challenge receipts conservatively; no clock origins are assumed equal. This interval proves its declared bounds, not overall mission acceptance.

Native process restart is an explicit one-time source lifecycle. After a public force-stop, Root verifies actual cold absence and the unchanged installed APK, retains the old STATUS/ACK/key/journal prefix as UNKNOWN until cold replay, then observes a distinct process epoch and P256 key with no restored grant. Immutable second registration binds to the first. Unexpected epoch/key/input actor changes remain terminal. The continuous log observer and global STATUS/command credits do not reset.

Raw export begins only after genuine product/native and Root flight resources are drained. It includes original FDM/AP transport, product/WAL/media and native original observations plus registration/clock proofs. The original native full-files TAR is a second complete stream. Streaming gzip/TAR stays within the original host 192 MiB aggregate and retained partials are never published. Android SAF must carry every bundle and native part plus the exact bare Root manifest document. `saf_stream.py` reads original `adb exec-out content read` pipe bytes from source-enrolled immutable native URI receipts with <=64 KiB memory, exact SHA/count/both EOF, bounded cleanup and no second host archive copy. The independent receiver still must verify the actual recipient streams.

Normal mission closure requires actual source ground and closed journals. Exceptional physical disposal closes only positively owned simulators, preserves FAILED/UNKNOWN and never fabricates normal closure or PASS. Parent death closes admission and triggers bounded cleanup. After genuine AP/backend drain and no-input proof, the flight monitor closes with its original 180/760-second scope. A separate <=300-second delivery phase keeps the source guardian/power/disk/budget/native/Node checks live through gzip and SAF; delivery time never counts as flight duration. All actor-free tests are labeled mocks; no mock count certifies Android, SITL, graphics performance, real payloads or hardware readiness.
