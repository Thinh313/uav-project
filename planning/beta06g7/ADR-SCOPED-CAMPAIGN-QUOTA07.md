# G7 quota scope decision

The retained historical tree is evidence, not a consumable current-session allowance. G6 failed because its legacy4096 entry counter included retained history. A new-only4096 cap is also insufficient:4worst-path AP launches can emit over5100 capture files before fixed state/UI files.

Use an immutable historical inventory and a declared bounded new campaign with derived8192 entry allocation. The old200/256MiB global allowance cannot cover existing hard writer maxima; replace it only for the explicitly authorized G7 campaign with an enumerated allocation below2304MiB early/2560MiB hard and256MiB closure reserve, subject to independent arithmetic and enforceable finite writer caps. Report total historical+new bytes. Preserve all physical29/28/20GiB and trend protections, original clocks/authority/control/fidelity and old evidence. This is an explicit engineering policy change, not a claim that worst-case fits the old allowance.

Admission checks shared between all layers precede host and every Connect effect; current usage plus remaining reservations and closure must fit. Existing per-file limits remain unchanged where possible; new count/record limits make previously implicit writer maxima enforceable. No old-file edit, evidence deletion, automatic failed-run retry, privilege expansion or production signature.
