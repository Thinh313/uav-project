# IOCommit09 design decision pending minimal Builder proposal

The measured blocker is not fixed by weaker freshness or a faster consumer alone. Durable input/renewal currently spans multiple barriers and uses pre-IO clock to publish authority. New isolated repair must make commit completion the linearization boundary, preserve original producer/UI clocks, and refuse continuity when prior lease expired while writing.

A bounded group commit for the single logical input/renewal transaction is permitted by the user's IO repair request. It must be explicit in versioned journal/reader semantics, preserve all input data and single-writer durability, and never permit socket entry without durable intent plus fresh pureapproval. No broad multi-record batching, samplecoalescing, clock-retiming or arbitrary asyncdispatch is authorized. Builder proposal and independent fault/reader QA precede actualshort.

Previous07/08 experiments remain sealed;09 is a new separately identified campaign with fresh actual resourcebaseline. No intervalsum/historyrewrite/newSDK/productionrelease. Stop afteractual09shortfailure;30conditional on allgates.

L2 accepted after independent QA conceptual review: one CONTROL_INPUT_TX record carries full original input plus proposed renewal/release; its single fsync is the input transaction's durability boundary. Read actual clock after return, validate prior lease/current input/attached UI/context/fence/lifecycle, then publish only valid state. Producer-based expiry is unchanged. Bounded pending receipt records the already completed barrier and decision, bound to exact transaction ordinal/raw SHA/full context, and is durably carried by next transaction, existing wire binding BEFORE its TX_INTENT, or explicit close/failure. This avoids claiming knowledge of a future fsync completion in bytes written before that completion. Consent follows same candidate/decision rule.

Reader must require groupDurableNs <= decisionNs <= carrier recordNs, one-to-one exact transaction resolution, continuous prior lease at real decision and all original freshness floors. A candidate alone or unwitnessed crash tail is UNKNOWN, never authority. Healthy terminal must resolve pending receipt; carrier storage failure remains uncommitted prefix and cannot permit later wire. Known rejection clears consent, no regrant. Full invalid tuple is retained bounded in new09 for diagnostic precision. All other per-record barriers and legacy byte/API contracts remain unchanged.
