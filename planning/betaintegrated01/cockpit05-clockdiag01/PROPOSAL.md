## Availability design for Root review, not implemented

A clock.poll() call inside currentdispatch is invalid: record_frame owns the writerlock and is in INTENT_DURABLE, while the currentclock sink appends EVENT only between fullframegroups. Polling there would cause SINGLE_WRITER_BUSY/phasefailure, so no such shortcut is used.

Propose an independently durable clockowner with its own single-writer boundedjournal and exact run/epoch/boot/AP/sourcebindings. It can receive and durably publish valid rawcorrelations while the mainframeowner is blocked onINTENTfsync. The frameowner consults only a fully published bracket, still checksage<=250ms immediately before actualsocketcallback, and records bracketID plus clockstreamanchor/context. If the clockowner dies, failsdurability, regresses, losescontext or becomesstale, failclosed without sending or replaying a frame. All validrawclockevents remain retained. Frames/model/clockthreshold/cap500/speedup1 are unchanged. Main and clock streams need explicitly versioned coldassociation/order checks and final external anchors; a dictionaryupdated beforeclockfsync must never count as observedfresh.

A provisional64MiB clockjournal quota with1MiBsegments is a conditional cap, not a guaranteed1960second formatbound: the existing enforced clocklimit can allow237100 events, each up to2048bytes, so a loose formatbound is approximately463MiB beforemetadata. Keeping the main6GiB quota while adding64MiB raises totalhardpeak and admission by64MiB; no capacity claim is made until Root approves exactquota/count/oracle/storage arithmetic. If the independent clockjournal itself stalls longer than250ms, refusal remains correct. This design improves availability only when clockwork can proceed during mainIO wait; it is not guaranteed against a hostwide pause or common-filesystem stall. Mockinterleavings, boundedfaults, sourceclosure and shortactual would precede any newlongattempt.

Repositorysearch found existing io59/alloc60/isolate61/thread62 timing-attribution implementations and beta06g11/g14 clockbasis code, but no reviewed drop-in independent durableclockjournal matching the current M1 fullframe contract. Prior attribution explicitly warns that nonCPU wall, sampled schedulerstate and D-state alone do not prove filesystemcause. Those are references only and remain immutable.
