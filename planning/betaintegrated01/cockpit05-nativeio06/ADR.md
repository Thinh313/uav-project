# ADR: cooperative bounded FIFO service and native IO attribution

The accepted NativeIO03 top-of-loop drain does not bound time from a newly offered input to the next admission when several durable read-only requests and RX processing occur before tick. Actual closed Observer05 rows establish that a timely produced sample remained pending until tick revoked its old lease. They do not separate fsync, output callback or descheduling cause.

Choose a measured, minimal single-owner change: retain the existing FIFO128, producer timestamps, same authority/session algorithms and max16 admissions per complete outerloop, but allow remaining admissions at explicit IO boundaries. Diagnostic snapshots use a bounded ring plus aggregates, with wall and threadCPU domains labelled; normal measurements add no per-observation fsync. Record write/fsync/socket/queue and owner phases, and retain exact failure cause if diagnostic publication fails. Single actual operation stalls may still cause correct authority expiry; do not disguise this with retimestamps or larger TTL.

Reject unbounded queue draining, newest-only input coalescing, concurrent wire writers, skipping durable TX_INTENT, retrospective sample acceptance, threshold changes and implicit authority restoration. Do not adopt an independent input writer until the measured single-owner result justifies new cross-stream protocol complexity. New NativeSegments source, if needed, is instrumentation-only and must preserve exact raw byteformat, CRC/chain, rotation and fsync-before-wire semantics. All old code remains immutable.

New separate APK/package and test namespace bind exact core/sourceidentity, same UI and physical profile. Diagnostics are separate local observations, not native authority or aircraft execution proof. Mock baseline-vs-candidate comparisons hold input/clock/fault scripts constant; actual short must separately prove raw/control/geography/freshness/ground/restart and exported diagnostic provenance. Measurement overhead and real-vs-synthetic clocks are disclosed. The long gate remains conditional on short independentPASS, durationfeasibility and fresh resource admission.
