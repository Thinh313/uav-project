# CREW02 independent QA check plan

The frozen input is `evidence/crew02-qa/heldout-corpus01.json`, SHA256 `875dbde450c3d3b9760737a479a40de283bb3743ce97f0489fac82a5ab1ab8b5`. It binds TIP SHA256 `5acb670d320a5f663a04689c97249f7732181f84ad3b48323b0ad1d8f5286530`. Nine parameterized cases were authored before inspecting the CREW02 implementation. Seed, nonce, identity labels and operation values remain undisclosed to Builder until source freeze. This is separate AI QA, not independent human review.

CH01 tests actual TLS possession and endpoint trust, without treating authentication as authority. CH02 tests byte framing and strict JSON. CH03 tests identity aliases, session/replay and live trust changes. CH04 tests CAS and post-WAL rechecks. CH05 tests independent aircraft/camera/gimbal scopes and selections. CH06 tests recipient consent and frozen old intents. CH07 tests multiple camera routes, capabilities and manager ambiguity. CH08 tests real B partition while A continues. CH09 tests pilot/common loss, reboot, persistence, export and preservation.

The corpus uses abstract typed QA intents, not a claim about an unfinished production JSON API. After source freeze QA will create a separate digest-bound API mapping. Mapping may rename selectors/fields, project flight-only versus payload channels, or separate framed-byte extraction from typed application admission. It must preserve frozen values, order, refusal outcomes, zero-wire assertions and safety bounds. A semantic conflict must be reported to Contractor; it is not permission to change original expectations or fixtures. A valid frame does not imply an authorized request. Rejecting every input cannot pass because valid join, scope and command actions must succeed in the same check plan.

QA may execute bounded host tests and offline decoders. Root exclusively launches Android/SITL, operates the owned emulator and records actual UI/runtime evidence. Actual TLS results must include peer leaf/SPKI, negotiated protocol/cipher and accepted identity at both boundaries. Wrong identity/pin/plaintext cases must fail before application admission; separate certificate-validity probes must isolate validity rather than accidentally proving only an unknown-key refusal. Secrets stay outside evidence, APK, browser and VCS.

Native raw is the command/control evidence: authenticated principal, current policy/session/boot/generation, intent digest, durable intent, final approval and exact one wire attempt must bind together. Upstream MAVLink decoding independently checks targets, units, sequence and synthetic peer routing. TLS cannot authenticate an unsigned MAVLink peer or prove an exposure. ACK, response delivery and execution remain distinct.

C01–C12 remain NOT RUN until their required classes of evidence exist. Host fault tests do not replace Android foreground/lifecycle, independent process partition, real TLS, actual SITL observer, process/coldboot persistence or export receiver. Optional UI diagnostics and their quotas are separate from native flight transport. A new explicitly started evidence generation may be used after retaining a failed run, but cannot erase the failure or restore authority.

Preserve legacy source/candidate/ENDURE and the P1 source/evidence fingerprint. Do not launch runtime, mutate ADB, edit production, weaken bounds, delete evidence or spawn agents from this QA role. Record targeted source findings with severity and a falsifying example; avoid test-count claims as product capability.
