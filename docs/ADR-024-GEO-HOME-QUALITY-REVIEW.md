# ADR-024

New survey-run v2 carries a pinned engineering quality-policy reference and requires explicit fresh Home/source review. Keep v1 records and source bytes intact. Snapshot each guard in the recorder, validate by deterministic replay with original geodata, and preserve through existing wire/receipt schemas. Reject stale review and changed policy/source/session; revalidate live Home at every command boundary. All AUTO commands require fresh matched Home, while emergency HOLD/RTL bypass new approval. Datum conversion is a separate explicit algebra contract with matching geoid model/coordinate context, never a silent EGM2008/MSL equivalence. Continuous grid-cell conservative bounds replace false inference from sparse samples in the review, without claiming field obstacle safety. Measured survey criteria remain declared/not-checked until observed hardware/data validation exists.
