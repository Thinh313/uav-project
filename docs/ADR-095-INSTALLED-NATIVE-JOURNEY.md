# ADR095 — installed native journey before a live bridge

Reuse the existing offline Activity/WebView and PREFLIGHT43-portable/NATIVE44 workflow, deriving a separately identified development package. First close actual Android app-private persistence, lifecycle and operator journey. Emulator verification is not HeraHub compatibility or radio/video acceptance.

The earlier APK31 validates a different revision. New package79 carries exact44-derived assets, source hashes, debug-only certificate and explicit mock labels. It retains no network permission and cannot call a flight endpoint. Production keys/candidate/trust are untouched. Current development signing and simulator-step authorization permit this local installed test.

Keep the native live MAVLink integration as the next gated increment: it must use the installed shell’s session/boot/focus ownership, explicit simulator-only endpoint attestation and durable outcomes. Do not embed a browser control page and call it native-core acceptance. No Android mock result can promote unresolved Home/AUTO, sensor-loss, stable1×, payload/Hera or ENDURE gates.
