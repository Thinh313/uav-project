# ADR-016 · mission-pattern acceptance before operator comparison

Use a versioned corpus and pre-run source/runtime freeze to exercise the existing compiler and simulator profile. Independently generated surveys complement the pinned actual QGC corpus, with provenance kept distinct. Rejected requests are first-class cases; unsafe concave transitions are not repaired or silently accepted.

A pure validation/report module binds execution records to case source/compiled hashes, freeze identity, profile and per-trial reset. A read-only page imports/exports the package and displays engineering observations. The server can serve only the fixed latest local receipt through a GET endpoint. It never initiates a trial or sends a flight command.

Automated SITL observations do not measure operator touches, human task duration, native performance or superiority. B is NOT_CHECKED and this version rejects invented B observations. A formal black-box operator protocol is deferred until observed RAGAS binary/runtime/device configuration exists. Digest integrity does not establish signed provenance or a randomised comparative experiment.
