# ADR-032 · Wire correlation is bounded evidence

Accepted2026-10-13 within authorized offline protocol increment. Retain candidate9 and PAYLOAD21 frozen sources. New browser-neutral Uint8Array codec and offline session engine are not an aircraft transport. Official C headers generate golden packets; a separate JS codec handles bounded selected message definitions from pinned XML. Reference C oracle tests serialization independently, not semantics on Hera. Signed MAVLink frames are refused until verification/key custody is implemented; no downgrade fallback.

Identity: aircraft/session/transport generation + responder system/component, camera proxy device ID, manager/device ID, and information discovery generation. Camera/gimbal assignments require explicit camera-information device linkage and observed manager information; do not infer from Front/Center/Rear. Discovery information can arrive before ACK; it establishes advertised capability, not command execution. Proxy ACK uses result_param2; proxy messages missing identity cannot be assigned arbitrarily. No SDK/installed capacity inferred.

ACK has command/result/responder, optional recipient IDs and proxy result_param2; it has no local request UUID or original command parameters. Serialize one pending ACK key per responder/command, including discovery512 requests. Retain receive sequence/boot baselines, reject stale/replayed/foreign context, and quarantine unresolved ACK keys until explicit new generation. Even a matching accepted ACK is only acceptance evidence. Fresh CAMERA_SETTINGS/CAMERA_IMAGE_CAPTURED or valid device attitude matching a setpoint is OBSERVATION_CONSISTENT_UNATTRIBUTED, not proof that this request caused it. Capture messages/URLs never create authenticated images, successful-file hashes or accepted survey quality. Lack of a camera definition/calibration leaves limits and focus values unknown. ZoomLevel is percentage, not PAYLOAD21's synthetic zoom factor; no silent unit conversion.

Gimbal units: manager information limits are radians and device attitude is quaternion. SET_PITCHYAW message287 uses radians; COMMAND_LONG command1000 uses degrees and degree/s. The corpus encodes command1000 and compares quaternion-derived degree angles against those setpoints; display can convert limit radians to degrees. Device yaw vehicle/earth flags are required to compare yaw frames; refuse unknown/conflicting frames and failure flags. Configure ACK does not grant control; primary manager-status must identify this GCS and stay fresh. Secondary authority and mission takeover are shown separately and not treated as primary. Unknown/asymmetric manager-device routes require explicit configuration before control.

Current integration boundary: protocol inspection/replay only. Future Fly binding sends exact reviewed envelopes and receives explicit typed states; legacy mission compiler/archive scope stays unchanged. After ENDURE20 accepted/selected9 and closed canary, verify current pinned module/report/corpus, implement gated Fly inspection view in a new version, run full tests/browser/corpus/signature/staged-canary preservation, then select the new release. Actual hardware commands remain disabled. If ENDURE20 fails, no signing/selection bypass; repair or repeat24h separately. Owner authorized the later integration, not external commercial release.
