# ADR-031 · Independent aircraft and payload adapters

Accepted in authorized hardware-free scope, 2026-10-13. Working increment PAYLOAD21, separate from frozen ENDURE20.

Separate aircraft transport/flight authority, camera controllers, gimbal managers, stream health and evidence. A screen selection is a viewing choice; a command carries an immutable exact route and session. Identity is not a Front/Center/Rear label. Camera component addressing and autopilot proxy camera IDs are distinct. Gimbal commands target a manager plus its device ID, never an inferred camera component. Discovery provides supported functions and limits; missing information means disabled control. Synthetic fixtures do not define Hera's installed payload count or limits.

Future transport interface: connect(observedConfiguration), disconnect, receive typed observations, send exact protocol envelope. Future flight adapter owns preflight/profile/Home, flight mode/arming/mission transactions and telemetry; payload errors cannot fabricate flight mode changes. Camera adapter owns discovery/health/settings/capture/stream metadata. Gimbal adapter owns manager discovery, primary/secondary control status and constrained setpoints. Video adapter exposes frame age/feed identity independently of control heartbeats. Evidence sink receives original messages plus decode/version/aircraft/session/frame/unit/time provenance. PAYLOAD21 only implements an in-memory simulator of these seams; real adapter construction fails closed.

Commands transition REQUESTED → ACK_ACCEPTED → OBSERVED_SIMULATION only with matching target/session/request/operation and measured simulated feedback. ACK means accepted, not observed execution or physical image. Negative ACK → REJECTED. Loss/fault/revoked authority → UNKNOWN; deadline → TIMED_OUT_UNCERTAIN. No automatic non-idempotent retry. Bounded one outstanding operation per target. Local correlation IDs are not MAVLink transaction IDs: a future wire adapter must serialize command ACK matching by route/command, quarantine ambiguous late ACKs and separately correlate capture/attitude observations. PAYLOAD21 does not encode MAVLink bytes or promise universal camera/gimbal protocol support.

Capability, authority and control feedback are distinct. Camera stream loss does not imply camera control loss; an available stream does not prove current control authority. A gimbal fault disables gimbal operations, not camera capture or flight. Payload disconnect invalidates its discovery/authority and outstanding outcomes. Aircraft disconnect invalidates all payload control and session; reopening never resumes commands. Explicit rediscovery and operator reacquisition precede new commands.

Design: operator console uses IBM Plex Sans already licensed by the project, black #000000, white #ffffff, surfaces #15181c/#22272e, text #c7ced6, yellow #efcd36 as a small active-selection/control accent. Large primary view retains feed identity and simulation marking; payload selector and thumbnails form one aligned row; persistent aircraft state and explicit payload control occupy separate regions. No invented photoreal video. Synthetic scene shows orientation changes without claiming camera quality. Shared44px minimum control sizing; responsive stack at narrow widths. Review removes ornamental KPI cards and generic dashboard scaffolding.

Integration gate: retain this isolated module until ENDURE20 terminal acceptance; then integrate adapters with observed configuration validation, current compiler/archive/contracts, new signed release and full regressions. Real transport, media decoding, manual flight sticks, native runtime and HIL/field acceptance remain NOT_CHECKED. No official release or signer identity implied.
