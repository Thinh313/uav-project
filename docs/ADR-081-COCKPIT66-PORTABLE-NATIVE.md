# ADR081 · portable cockpit against frozen CYBER65

CYBER65's Node crypto/Buffer helpers cannot load directly in Android WebView. Derive selected modules into native/cockpit66/portable, preserving originals and recording hashes. Replace only Node hashing with the already-qualified N44 bounded SHA primitive and Buffer byte length with TextEncoder; keep semantic/authority/protocol behavior unchanged and compare all44 corpus digests against original Node replay. T25 digest remains WebCrypto; no unknown Phase One API or operational transport is added.

Browser testing later identified interpreted-angle rounding differences; ADR082 records the exact evidence and constrained comparison policy. No control algorithm, source hash or workspace digest is rewritten. Node parity still requires44 exact digests; browser displays exact and numerically compatible counts separately.

Cockpit uses local mock identities as two operator perspectives within one shell. Grouped camera/gimbal handover composes explicit CYBER65 transfers, freezes both, checks recipient consent, and revokes the bundle on an incomplete commit. Selection is independent of authority. Logical mock clock advances by explicit steps/actions; no host performance or real-time latency inference and no deadline increase.

Workspace persistence is an explicit saved action-tape/review capsule, not a claim of a durable command journal. Load replays in a separate isolated mock and checks expected result hashes; then discards all replay authority and creates a disconnected live model. IndexedDB uses bounded transactional CAS; historical imports cannot issue commands. An uncertain storage result blocks further actions until explicit load/reconciliation. No automatic retry or pruning.

Android wrapper source intercepts only bundled HTTPS assets, blocks network/file navigation and exposes no radio/flight bridge. Lifecycle callback revokes the volatile mock session; actual onPause/window-focus delivery/ART/IndexedDB durability must still be qualified on Android. Browser focus fault tests do not close those hardware/runtime gates. At current disk space, no emulator/image download, APK/build or signature is attempted.
