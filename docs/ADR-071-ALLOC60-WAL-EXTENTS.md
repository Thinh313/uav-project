# ADR071 — reserve extents, retain logical WAL

Scope accepted by explicit user instruction. Use local Apple SDK sys/fcntl.h F_PREALLOCATE42, flags F_ALLOCATEALL4, posmode F_PEOFPOSMODE3 and fstore_t32-byte layout on Darwin64. Local SDK header fingerprint retained. It reserves physical storage without changing logical EOF. F_ALLOCATEPERSIST omitted so unused reservation may be released on close by OS; never truncate/delete evidence. No POSIX fallocate (changes size) or zero-fill alternative. No fallback if unsupported/partial. Both experiment variants keep identical syscall/wake instrumentation and physics/control. Four counterbalanced runs are descriptive on a shared host, not statistical proof from two samples. fsync remains per INTENT before sensor send; no async/group commit or altered durability.
