Keep AP binary, rate, cap, model and durable per-frame journal. Do not move physics into Linux: retained linux-oracle rejects exact bytes at frame10. Optimize only host receive/serialization/scheduling; use a controlled same-version baseline. Reuse frozen UI/scene files through explicit derived adapters and record origin hashes. Separate received-but-unadmitted shutdown tail from completed frames, finish already admitted frames before seal.
