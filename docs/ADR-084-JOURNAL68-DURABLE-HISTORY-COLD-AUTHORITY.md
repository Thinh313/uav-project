# ADR084 — journal before effect, historical recovery only

DUAL67 remains unchanged and volatile. JOURNAL68 wraps its pinned Arbiter in serialized admission. A new WAL starts with OPEN containing boot/corpus/source/initial-state and parent recovery SHA. For each admitted event, INTENT is written/synced first; then mock dispatch runs; OUTCOME containing exact return/error and checkpoint SHA is written/synced before response. Write/sync uncertainty stops admission and clears volatile authority. No POST retry. A clean stop journals CLOSE and OUTCOME, then SEAL.

Framed records encode bounded UTF8 byte length and canonical payload SHA, seq and previous SHA. Catalog records bind each WAL's exclusive filename and OPEN hash. Catalog/file mismatch or semantic corruption is read-only HOLD. A partial final frame is retained without truncation; only the complete committed prefix is replayed. A full INTENT lacking full OUTCOME is UNKNOWN_NO_RETRY; recovery never dispatches that intent. Existing valid bytes observed on restart do not prove the previous fsync returned or the client received the response.

Every restart creates a new Arbiter/boot/token map. Historical replay runs in an isolated instance for checking and produces read-only records, never credentials or live authority. Historical owners/pending are not current owners. Source mismatches are unsupported recovery, not silently migrated. No old run is resumed or edited, and no lock/evidence is removed.

One writer is enforced using macOS/POSIX advisory flock through a tiny Python stdlib child holding a persistent lock inode. Parent pipe closure or child exit releases the OS lock; unexpected child loss fences the wrapper. The lock file is never deleted or renamed. File/directory fsync and actual process SIGKILL are host tests; they do not certify physical power-cut behavior, F_FULLFSYNC, Android filesystems or malicious concurrent writers that ignore advisory locks. Local hash chains/catalog detect consistency failures, not authenticated provenance or coherent whole-store rollback without an external trusted anchor.

Preview8823 derives only small DUAL67 UI assets and adds journal/recovered-history views. Local role fixtures, synthetic media/camera observations, explicit-step core clock and outer host clock remain unchanged. No SDK, Android qualification, signature, flight link or ENDURE action.
