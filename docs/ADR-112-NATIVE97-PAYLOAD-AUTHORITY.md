# ADR112 · Native payload arbiter with AP routed synthetic peers

Accepted for isolated NATIVE97 engineering. Reuse CYBER65/DUAL67 semantics and APROUTE28 topology; implement enforcement in Java at the socket send boundary. JS cockpit holds no wire injection API for payload. Local mock role handles are memory-only, explicitly joined, not remote authentication. Bundle ownership is camera+gimbal for each selected payload; view selection never transfers ownership. Aircraft authority is separate and not mapped to flight commands by this adapter.

Read-only discovery requires fresh disarmed AP and component heartbeats. Unsigned routed fixture data cannot authenticate a real aircraft or prove execution. Fixed targets100/102/101/154 and devices1/2 only; no broadcast or autopilot component commands. Sender255/190 on AP SERIAL0; peers on SERIAL1/2. One command per ACK endpoint+command key per generation conservatively fences ambiguous same-manager ACKs; repeat/continuous controls remain a gap, not silently guessed correlation.

Raw journal fsync before RX application/TX write. Session/boot/clock/lifecycle/authority changes revoke, pending commands unknown, no retry/regrant/reconnect. UI uses existing Barlow/black-white/yellow glass cockpit; adds a two-station workbench inside Workspace without changing frozen/product source. Actual hardware Phase One controls, two remote stations, secure enrollment and mission-flight-plus-payload concurrency are separate gates.

Actual QA refinements: the pinned AP dialect lacks newer camera_device_id extensions for259/260, so only direct component/device0 is supported and newer nonzero extensions are refused by strict length. AP startup can interleave printable ASCII; allow <=1024B only in first15s before stations/transactions, never after admission, with strict CRC retained. UI uses explicit target buttons after dropdown/keyboard selection proved unreliable in the Android harness; unchanged render state is deduplicated. Diagnostic keeps2MiB/generation and16MiB total, only modal active controls are emitted; covered background controls are omitted, stale receipts never used.
