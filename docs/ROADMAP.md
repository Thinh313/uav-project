# Delivery roadmap · gates, no committed dates

Owner decision 2026-10-12: independent RtR GCS to replace RAGAS through A/B evaluation, competitive by workflow with DJI. No RAGAS application source reuse. Survey is the first workflow of the full flight/payload/mission/data product. AI-native development is supported by contracts, deterministic cores and executable evaluation evidence; runtime AI flight authority is not implied.

| Milestone | Deliverable | Exit gate |
|---|---|---|
| M0: kickoff | Captures/claims/SOT, requirements, local workbench | Required M0 AC pass, simulation boundaries visible. |
| M1: independent architecture / device baseline | New module contracts, open dependency/license inventory, RAGAS black-box workflow baseline, HeraHub/device inventory | Independent architecture ADR and measured device integration decisions. No RAGAS source-access gate. |
| M2: flight/mission correctness | MAVLink state/transactions, compiler, geospatial/DEM/schema engine, pinned QGC interchange fixtures | Golden/negative fixtures and actual SITL telemetry/upload/readback/execution/camera traces. |
| M3: field alpha | Native HeraHub integration, video/input, offline maps, RTK/payload/replay | Exact configuration passes HIL, failure/stress/offline and measured runtime budgets. |
| M4: survey beta | Complete operator journey, logs/media, signed releases and migrations, A/B sessions | Controlled trials, usable results, no flight-critical P0, task-level A/B evidence. |
| M5: commercial release | Supported configurations, training/support/security/SBOM | Authorized commercial acceptance with exact build and evidence. |

Dependencies: new architecture and hardware observations → Android packaging/integration; compiler and simulation fixture → SITL; GEO/DEM/QGC fixtures → operational mission compiler; SITL + device configuration → HIL → controlled flight. RAGAS source is not a dependency. Open protocols and independently inspected open-source components may be used with provenance/license inventory.
