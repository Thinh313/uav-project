# GEO14 · review before survey

Choose a retained corpus plan or import an AERIS survey. Select the simulator vertical policy. The review shows source hash, original DSM reference, conservative model bound, predicted GSD/overlap and uncalibrated camera declaration. Resolve any planning failure in the source survey rather than overriding a failed criterion.

Connect the dedicated local SITL, read Home/profile and compare. Home must be fresh and within the pinned simulator reference. Check source, mapping and scope, enter a review note and the displayed digest code. Review is source/session/policy-bound and lasts 30 seconds; every upload/ARM/AUTO checks live Home again. Expiry/change requires explicit renewed review. HOLD/RTL remain available. This page only uploads after review; it never ARM/AUTO automatically.

New survey-run v2 carries policy reference 1.0.0. Earlier v1/QGC records retain their original semantics and hashes; fresh Home also guards legacy AUTO. Each new record contains replayable source/policy/Home/geo snapshots, original pinned geodata and guard events. Existing streamed handoff keeps these bytes.

The recipient selects a verified report of format aeris-survey-quality-report v1. It contains recordSha256, provenance and metrics (gsdCm, coveragePct, usableImagePct, horizontalRmseCm, verticalRmseCm, independentCheckpoints). Null means NOT_CHECKED. The server reads metrics from those exact verified report bytes, not arbitrary browser fields. Targets are an AERIS engineering policy, not an industry certification/client order. Synthetic or imported declarations may meet targets numerically; capture authenticity, camera calibration, field datum tie and actual survey quality remain NOT_CHECKED, with fieldAccepted=false. The portable assessment binds report/record/policy hashes and declared units.

DSM surface objects, approximately 30m context, unknown per-pixel error, current obstacles and actual trajectory/landing geometry prevent field clearance approval. EGM2008, ellipsoid heights, unspecified MSL and Home-relative heights cannot be silently interchanged. Algebraic conversion requires a source-bound geoid separation at the exact coordinate; it stays a declared non-operational conversion until actual integration/verification exists.

Primary basis: [MAVLink message definitions](https://mavlink.io/en/messages/common.html), [Copernicus DEM description](https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM), [USGS datum documentation guidance](https://www.usgs.gov/about/organization/science-support/office-science-quality-and-integrity/guidance-use-and). Scoped definitions and raw/extracted snapshots are retained in research/geo-quality-20261013; USGS raw HTTP 202 is a failed raw capture, with the official web-tool excerpt separately labeled. Those sources do not supply or certify the engineering thresholds.
