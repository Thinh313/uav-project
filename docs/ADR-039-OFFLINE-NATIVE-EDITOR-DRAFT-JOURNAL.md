# ADR039 · Editable native survey without geometry fork or new signing

Accepted for isolated NATIVE30 engineering prototype13/10/2026; not final production-stack decision. The previous N29 six-plan catalogue cannot author arbitrary bounded AOIs. Porting geometry to Java creates an unverified second implementation. Reuse the pinned frozen survey/compiler ES modules through a local offline WebView with an allowlisted synthetic HTTPS origin. Android Activity owns lifecycle and a bounded async Java storage bridge. No network permission, arbitrary URL navigation, external assets or flight endpoints. Browser reference uses the exact same editor modules with the Java journal behind a localhost-only test service.

Mutable form is separate from compiled mission and mock execution. Every form edit clears compilation/preflight gates; current errors retain editable text. Active mock run refuses edits. Save binds exact form/compiled bytes and source pins, never command authority. Restore recompiles under current pinned core and compares raw mission bytes; mismatch/unknown/tamper prevents a ready plan. All coordinates/altitudes remain the existing≤500m simulator world, camera demo/unmeasured.

Persistence uses immutable revision records with exact body byte SHA, previous-token chain and a separately atomically replaced head. Exclusive file lock + expected head prevent stale tab/process overwrite. File and directory fsync are required; failure is surfaced. Published orphan revision remains evidence after crash; pending head blocks writes, no implicit forward selection or deletion. Restart can recover the old committed head or new committed head according to the actual commit point; never invent completion or restore input/video/run authority. Quotas are policies, not measured Hera capacity.

New signing is explicitly excluded. Build N30 unsigned; ART can execute test DEX without installing an APK. An unchanged older signed diagnostic N24 APK is a separate installed-runtime probe, not N30 UI acceptance. Never relax PackageManager signature checks or modify image security to install unsigned APK. New Activity/WebView runtime remains NOT_CHECKED until an authorized signed artifact can be installed. Emulator evidence does not establish Hera hardware/SDK/video/RC mapping. All frozen artifacts/ENDURE failed receipts are retained.
