# Adapter contract and real-device admission

Implemented runtime: Node host gateway and browser synthetic media source. This is not an onboard Linux deployment, Sony Camera Remote SDK implementation or HeraHub driver. All available devices are explicitly MOCK, with actualImages=0 and no flight API. The explicit receiver/export format is the existing BIG02 synthetic format; real media requires a separate versioned schema and acceptance, not relabeling these artifacts.

`MockAdapter.discover()` returns descriptor identity, boot generation and capabilities. `invoke(deviceId, action, args, {signal})` may return a promise. The gateway serializes commands per device, journals intent before invocation, rechecks permission after WAL, bounds response wait to500ms, then verifies device/boot/action/source/readback and checks permission again. Timeout is UNKNOWN even if hardware could have acted. No automatic retry, rollback claim or authority restoration. AbortSignal is a request to cancel work, not proof that a device cancelled it. Only readback state can be reported as observed; a failed correlation is never interpreted as success. The500ms adapter response budget is unrelated to the frozen simulator's pacing cap.

Current gimbal units: degrees, pitch[-90,30], yaw[-180,180], explicitly body-relative mock frame; not a validated vendor/MAVLink convention conversion. ISO whitelist100/200/400/800/1600 only for RGB mock. IR mock cannot provide radiometry or ISO. `capture` separates intent/ACK, mock exposure event, JPEG bytes, metadata validation and durable commit. The media frame uses browser monotonic clock and a distinct browser boot; the device/host boot identities are retained in `gateway.json`. GNSS brackets and their5ms combined uncertainty are synthesized, not GNSS/PTP measurements. Images are aircraft-position-at-exposure examples; camera lever arm, spatial accuracy and target position remain unknown.

For the first real adapter, select an exact Sony ILX-LR1/lens/Pixy LR SKU/firmware/API topology. Required gates: Linux SDK license and redistributability, model discovery/readback, physical wiring and power, gimbal frame/sign/endstops/rate, exposure event/clock-to-GNSS correlation, original image download identity, real error/cancel/reboot/timeout behavior, and qualified radio/encoder/controller topology. Do not change the mock whitelist to admit real mode without new explicit profile, provenance schema and tests. No SDK has been downloaded or vendor license accepted by this milestone.

Phase One P3/camera SDK, radiometric thermal, LiDAR/corona and four-device concurrency are subsequent adapters. Sharing the command envelope is not evidence of their implementation. Production authentication, transport security and operator attestation are separate from this loopback nonce/mock lease guard.
