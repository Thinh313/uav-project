## Decisions

- A proxy retains the one upstream simulator socket after the GCS link is cut. This preserves independent observation without sending traffic that masks GCS failsafe. Observer observations never become an actionable live control source.
- Recovery does not silently restore a revoked connection or resume AUTO. The first implementation only acknowledges fresh ground/disarmed evidence then closes the interrupted session before a new readonly session.
- Existing review84/mission/archive83 formats retained. New failure-observer evidence is additive and is not a normal mission acceptance.
