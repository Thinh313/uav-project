# FIRMWARE38 — source-bound firmware and safety mapping, mock only

Separate namespace. Old source/candidate/native/Fly/ENDURE/receipts remain immutable. Existing Node/Python stdlib; no install, compiler, network service, transport, APK, simulator or signing. Incoming announcements/parameter/state/reference data are synthetic; all output control/execution/authentication flags remain false.

The local reference version is ArduCopter 4.7.1, from version.h and a 20-file SHA-pinned interpretation bundle. This is not proof of the firmware in the existing SITL binary or Hera. The fixture's flight custom bytes are literally MOCK0038 and its UID/board values are arbitrary mock identifiers, not device measurements. Contract revision, target/session/boot/link, source bundle, expected announcement and reviewed Home/Origin/Terrain datum/reference values are distinct.

`wire.mjs`: AUTOPILOT_VERSION unsigned v2 subset, uint64 capability/UID strings without Number rounding; CRC and exact frame length. Classic PARAM_VALUE raw 4-byte decoding for 8/16/32-bit signed/unsigned integers and REAL32. Bytewise integer bits do not pass through float conversion, including NaN-shaped UINT32 containers. Narrow bytewise integer high padding bytes are not treated as part of the integer. C-cast 32-bit integers with abs(value)>=2^24 are refused because adjacent source integers can map to the same float. REAL32 nonfinite and classic UINT64/INT64/REAL64 are unsupported. This does not implement PARAM_EXT or parameter writes.

`contract.mjs`: require fresh exact reviewed announcement identity, pinned source profile, MAVLink2/MISSION_INT/FENCE capability bits and explicit parameter encoding. Both modern flags together are contradictory. Deprecated PARAM_FLOAT alone is not a universal encoding signal. It is admitted only by the named, source-bound Copter legacy exception, backed by the pinned capabilities()/cast_to_float source. Generic bytewise is a protocol-test profile; it cannot supply Copter safety mapping. CRC/version/UID matching is correlation, not authentication.

`readback.mjs`: <=32 known names (28 required for full policy), one pass per current issued binding, typed/range/name/count/index consistency and acknowledgement-before-output mock journal. Named-read param_index65535 is valid, because the source returns the request's -1 index. Complete witnesses remain process-local: serialization, tampering, change notifications, changed firmware announcements, owner loss, stale binding or writer uncertainty revoke availability. The API accepts one complete unsigned frame at a time; partial/concatenated/signed input requires an upstream framer and is refused, rather than hiding an announcement inside the older stream decoder. Same announcement does not silently refresh authority. No automatic reconnect/retry/cache-authority restore. Every outgoing packet is PARAM_REQUEST_READ in MOCK_BUFFER_ONLY, networkSent:false.

`policy.mjs`: rich Copter action graph, not a lossy conversion to APFLIGHT36's simpler enum. GCS/RC/battery numeric actions differ. SmartRTL, RTL-or-Land, Brake-or-Land, auto landing/return-path fallback, warn and conditional terminate remain explicit possibilities, with mode-switch success unproven. FS_OPTIONS retains AUTO/Guided/landing/pilot exceptions and possible gripper behavior; a gripper side effect still depends on build/hardware availability, never execution evidence.

GCS trigger uses explicit synthetic AP-side guest-clock receipt history/latch, strict elapsed>timeout, equality hold and recovery-without-mode-restoration. It does not derive AP receipt or RC loss from host downlink. Radio and EKF event booleans require AP-side adapter evidence later; the current context is a declared mock snapshot. Ground/arming-delay/AUTO exceptions follow the selected source branches. EKF landing-with-position may disable GPS assistance without a new mode; AltHold may fall back to Land. This is not a complete reproduction of every firmware interaction, scheduling, backend or mode implementation.

Battery mapping is limited to the declared primary analog-current monitor profile. Capacity thresholds remain mAh, never remaining Wh. Selected raw/sag-compensated AP voltage and healthy/current/timer facts are required. Zero thresholds disable their checks. Voltage hold uses strict > and requires LOW_TIMER>0 and a nonzero observed start; LOW_TIMER=0 is not an instant trigger. Additional unhealthy-monitor, backend, multi-battery and actual calibration behavior needs separate acceptance. A warn-only action is not promoted to Land by continue-landing options.

`altitude.mjs`: Location::AltFrame 0 AMSL,1 Above Home,2 Above Origin,3 Above Terrain. These are not MAV_FRAME constants. Confirmed/current, boot/target/epoch/datum-bound reference snapshots must match reviewed IDs, elevations and points. Different min/max frames convert explicitly into the reviewed AMSL datum with uncertainty; missing/unconfirmed/changed reference, inverted band or terrain at a different point remains unknown. No terrain interpolation/geoid conversion is invented. Margins and boundary uncertainty remain visible. Active ceiling/floor mask is separate from configured bits/autoenable; floor activation is not inferred from FENCE_ENABLE. The result covers altitude only, not full geofence or physical breach/enforcement.

Reference parameter types come from AP_Int8/AP_Int16/AP_Int32/AP_Float and AP_Enum's Int8 backing. The table's numeric bounds are deliberately declared engineering mock ranges, not all official metadata recommendations. Complete policy requires all 28 current typed readings; remaining Wh and an equivalent legacy battery-energy config remain unproven. No admission to arm/fly is produced.

Fixtures/corpus/tests use explicit SYNTHETIC/MOCK_ONLY origins. Failed replay1 is retained: its wrong-build mutation accidentally shared the reviewed expected array; deep cloning now changes only the announced fixture bytes. Current source-bound tests/oracles and cold replay receipts are identified in delivery/COMPLETION-FIRMWARE38.md. No historical receipt is rewritten to PASS or used to assert uninterrupted original-path presence.

The generated Python oracle is test-only upstream GPL-3.0-or-later material; MAVLink XML licensing/provenance is reference/mavlink/COPYING. No production artifact or package was created.
