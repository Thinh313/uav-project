# MAVFLIGHT37 — restricted offline AP-FLIGHTOPS adapter

New source namespace, no Fly/native integration or frozen-source edits. Every outgoing packet is returned as `MOCK_BUFFER_ONLY`, `networkSent:false`. No transport, server, APK, simulator or signing workflow exists here. All wire inputs and receipts are synthetic; actual ArduPilot/Hera compatibility is NOT_CHECKED.

`wire.mjs`: pinned 18-message MAVLink1/2 subset, stable native-size field ordering, extension order, CRC_EXTRA, little endian, zero truncation, bounded stream parser and first/last byte receipt clock. Unsupported/signed packets are discarded. Header sender zero, malformed lengths/CRC and numeric/string/array bounds are rejected. CRC is error detection, not identity authentication. Absent extension fields are zero padded for parsing; unavailable measurement extensions remain unknown at the adapter boundary. Corrupt stream bytes may be resynchronized; no authenticity guarantee follows.

`session.mjs`: explicit mock target/session/boot/link/epoch supplied outside the wire; per-AP packet sequence highwater with wrap, duplicate/reordered refusal, per-message boot-clock regression/wrap and suspension/stale gates. Sequence gaps >=128 are ambiguous and refused; real high-rate/long-loss recovery needs a new, verified policy. AP time_usec may be Unix or boot time: do not guess its relation to the host clock. Partial frame age starts at the first byte, never the final fragment. No auto reconnect.

`fence.mjs`: <=64 items, one inclusion plus exclusions, polygon/circle commands 5001..5004. Coordinates encode latitude x/longitude y in degreesE7; circle radius is float32. Quantized geometry is revalidated, with <=0.02m coordinate and <=0.001m radius engineering budgets. Original and quantized plans/items have separate hashes. Local model scope and uncertainty are inherited from APFLIGHT36, not certified geodesy. Pinned AP fence readback uses frame GLOBAL(0), z/unused parameters zero. Other equivalent frame encodings are conservatively refused until separately proved. Altitude/actions are not encoded into these item coordinates.

One mock transaction/instance performs COUNT -> requested ITEM_INT -> upload ACK -> REQUEST_LIST -> COUNT -> all ITEM_INT readback -> download ACK -> named PARAM_REQUEST_READ/PARAM_VALUE matches. An ACK only starts readback. Strict sender, GCS recipient and FENCE mission_type prevent cross-target/mission acceptance; a missing type in v1 cannot upload a fence. Duplicate last-item requests may return two additional mock buffers; whole transaction deadline 5s, no autonomous timeout retry. A local journal UUID never becomes a MAVLink field. A completed proof is a live, process-local capability, not re-established by serialized snapshots; loss, timeout, writer failure or stale owner invalidates it. On-wire frames have no cryptographic transaction nonce, so authenticated replay protection is deferred.

Read-only expectations contain <=16 named parameters. Fixtures exercise 14 fence/GCS/RC/EKF/battery parameters with arbitrary mock values, not controller settings/recommendations/defaults. Only PARAM_VALUE type REAL32(9) is admitted here. Firmware integer parameter casting/bytewise capabilities and a complete normalized failsafe/configuration mapping are deferred. `WIRE_READBACK_MATCHED` proves the mock item and requested raw-value comparison, not normalized policy, altitude datum, active enforcement or execution. No PARAM_SET, clear, ARM, takeoff, mode-change or general command output exists.

`telemetry.mjs`: retain raw packet provenance, flags, sentinel/extension availability and explicit units. Combine fresh HEARTBEAT+EXTENDED_SYS_STATE for mode/landed, EKF_STATUS_REPORT+SYS_STATUS for estimator/sensor observations; retain HOME_POSITION and GLOBAL_POSITION_INT altitude distinctions. Mode numbers are the pinned Copter subset. Pinned EKF2/3 source emits sqrt(innovation test ratio), despite the XML field names saying variance: square these values before comparison with the core ratio threshold. This mapping is mock-only and does not establish the firmware running on Hera.

GPS_RAW_INT.eph is HDOP, never meters. Usable h_acc is converted mm -> m; missing/zero accuracy stays unknown. Battery percent, consumed mAh or consumed hJ do not establish remaining Wh. Consumed hJ/36 may be displayed as consumed Wh, with `remainingWhKnown:false`. Primary battery ID0 is separate from secondary packs; invalid temperatures/cell sentinels remain unknown. Home datum identities/confirmation, throttle-at-minimum, AP receipt history for GCS and independent RC availability are not fabricated from standard packets.

`assess(profile, t, supplement)` imports APFLIGHT36 pure preflight/failsafe functions. Wire-only assessment remains incomplete. Supplements must explicitly say `SYNTHETIC_ONLY`, be target/epoch/unit/time-bound, and cannot rescue absent/stale required wire sources or nonfinite estimator values. Known wire fields take precedence; publication uses the oldest contributing receipt. Normalized config/fence supplements additionally require a current issued fence proof, and are still synthetic declarations. This permits a complete mock journey without claiming hardware facts. FENCE_STATUS and COMMAND_ACK remain diagnostic observations; heartbeat RTL plus breach does not prove causality or execution.

Validation artifacts are append by attempt under evidence/mavflight37. `generate.py` used four pinned XML files and upstream mavparse/stdlib Python generation. Test-only upstream generated oracle.py/oracle-v1.py carry GPL-3.0-or-later provenance; MAVLink XML provenance/license is reference/mavlink/COPYING. No compiler/dependency install was used. Failed first generation, first oracle vectors, first logic/replay receipts remain preserved. The unrelated camera bitmask enum warning from the local upstream parser does not affect the 18 selected layout/CRC matches and is recorded in interpretation notes.

Commands for the current accepted evidence are listed in delivery/COMPLETION-MAVFLIGHT37.md. They only run host mock interpreters. ENDURE and the 41-file restoration history remain unchanged; byte integrity is not endurance acceptance.
